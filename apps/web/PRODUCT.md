# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
A small group of friends collecting and arranging shared ideas. Signed-in members use browsers and a Mac wrapper; anonymous visitors can view shared boards.

## Product Purpose
DoggyNote is a cosy infinite canvas for Markdown notes, to-do lists, images, links, files, nested boards, and stickers. Collaboration should help people work together without distracting them from their board.

## Capabilities and Constraints
Preserve offline editing, private Inboxes, inherited board permissions, comments, exports, and approved agent changes. Simultaneous note edits must merge safely. Browser, keyboard, mouse, pen, and touch are supported. Large boards retain viewport culling and low-detail rendering.

## Brand Commitments
Preserve the established cosy dog-themed identity and light/dark themes. Existing components and theme tokens are visual authority; multiplayer is a quiet extension of the canvas.

## Product Principles
- Protect work before acknowledging it as saved.
- Show who is working without taking control of someone else's view.
- Keep private boards and Inboxes private on every transport.
- Make collaboration usable on phones and with a keyboard.

## Evidence on Hand
Repository README, CLAUDE.md, existing theme tokens, canvas/navigation components, and browser tests. The user confirmed full note co-editing, presence, cursors, selections, follow, and temporary pings; signed-in members only, with a coordinated desktop update. Verification uses web browsers and the browser-served desktop configuration.
