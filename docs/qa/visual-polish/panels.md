## Independent review follow-up RV-01

[WebKit, populated agent list, light 360px](review/webkit-agents-list-light-360.png) was inspected after the integrated first pass. It showed the previous connection row painting in the dialog's top padding above the sticky heading. The same structural gap was present in admin and sharing header rules.

The header backgrounds now extend through their own panels' top and side padding. Matching padding keeps the title and close button at their prior visual positions, and the sticky inset reaches the scrollport's upper edge. Agent padding remains responsive (24px desktop, 16px narrow). The regression now checks the header reaches the panel's inner top edge and uses painted hit-testing at three columns in the top strip after scrolling, so a merely visible heading cannot pass. Fresh after screenshots and the test run remain assigned to the primary integration workstream; this follow-up did not start a competing runner.
